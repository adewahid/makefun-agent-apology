Entry for the [make.fun competition](https://make.fun/c/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0): one sentence of apology an AI assistant owes the person it works for — funny and human at once, a real comic turn about a real failure.

## The entry

> I'm sorry I set your 7 a.m. alarm in the wrong time zone, so you woke up refreshed, punctual, and an entire day late.

## How it works

`main.ts` (Node 22) writes the single-sentence apology to `/output/entry.txt`. The entry is 117 characters, inside the 1–200 character gate, and the program refuses to write anything that would fail the gate. Output is deterministic: repeated runs produce the identical file.

## Run

```sh
node main.ts
cat /output/entry.txt
```
